# Day Panel, Checklists, Smart Typing, Tick Animation & Performance — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a detailed day panel (tasks with checklists and formatted notes), smart typing, a tick animation, and cut idle CPU to near zero.

**Architecture:** Pure logic (checklist rules, parser, rich-note conversion) lives in `model.py` / `richnote.py` and is unit-tested without Tk. UI pieces (`anim.py`, `day_panel.py`) are thin Tk layers over that logic. Background threads hand work to Tk with `root.after(0, …)`; timers run only while something is visible or raised.

**Tech Stack:** Python 3.13, tkinter/ttk, ctypes (Win32), unittest. Existing deps only (pystray, Pillow, holidays, openpyxl).

**Spec:** `docs/superpowers/specs/2026-10-24-day-panel-design.md`

## Global Constraints

- Exactly one process (`pythonw.exe`), no child processes; no new threads beyond Tk, hotkey, tray.
- Idle CPU < 0.1 % of one core over 20 s (calendar on wallpaper, glow on and off).
- Memory < 70 MB working set with 200 tasks; day panel opens in < 300 ms with 30 tasks.
- No new dependencies, no web engine, no network access.
- Old `data.json` files load unchanged (missing `items` = empty list; `note` stays a string).
- Tests and scripts use a temporary data folder (`Store(tempfile.mkdtemp())` or `CALENDARDESK_DATA`), never `%APPDATA%\CalendarDesk`.
- Run tests with: `.venv\Scripts\python -m unittest discover -s tests -t .`

## Review Focus

1. Repeating task with a checklist: ticking items on one day must not tick them on other days → test in Task 2.
2. Smart typing text with no recognisable words, or only recognised words ("tomorrow 7pm") → title must never be empty → test in Task 3.
3. Notes with unusual lines ("1." alone, "-" alone, `**` unclosed, Windows line endings) must round-trip without losing text → test in Task 4.
4. Clicking a checkbox twice fast during the animation must end in a consistent state (one toggle) → test in Task 5.
5. Editing a task in the day panel while the same task is open in the task dialog → last save wins, nothing crashes, panel refreshes → test in Task 6.
